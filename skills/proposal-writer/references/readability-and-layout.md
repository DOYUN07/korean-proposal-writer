# DOCX 가독성 및 편집 기준

## 적용 우선순위
사용자의 명시적 지정, 공고·제출 양식의 의무 규정, 제공된 문서의 유지해야 할 서식, 아래 기본값 순으로 적용한다. 서로 충돌하면 임의로 한쪽을 무시하지 말고 해당 충돌을 설명한다. 지정 서식에 13pt가 요구되면 본문·표의 대상 범위에도 13pt를 유지하고 아래 12pt 기본값을 적용하지 않는다. 공식 양식의 표 구조나 항목을 가독성 개선이라는 이유로 바꾸지 않는다.

## 별도 지정이 없는 일반 제안서·계획서의 기본값
- 용지: A4 세로. 위·아래 여백 20mm, 왼쪽·오른쪽 여백 25mm. 표와 그림은 이 영역 안에 배치한다.
- 글꼴: 사용 환경에 설치되어 있는 한국어 지원 글꼴을 선택하고 본문 전체에서 통일한다. 맑은 고딕을 우선 고려하되 미설치 상태에서 동일한 렌더링을 보장하지 않는다. 본문과 표의 한글·영문 글꼴 매핑을 함께 설정한다.
- 문서 제목: Word Title 스타일, 20pt, 굵게, 검정. 한 문서의 주제와 목적을 명확히 나타내며 장식선으로 강조하지 않는다.
- 큰 제목: Heading 1, 16pt, 굵게, 검정. 위 12pt·아래 6pt 문단 간격을 기본으로 한다.
- 소제목: Heading 2, 14pt, 굵게, 검정. 위 8pt·아래 4pt 간격을 기본으로 한다. 필요한 경우에만 세 번째 계층을 12pt 굵게 사용한다.
- 본문: 12pt, 줄 간격 Multiple 1.4배, 문단 앞 0pt·뒤 6pt. 왼쪽 정렬을 기본으로 하고 문단 사이에 빈 줄을 추가하지 않는다.
- 표: 본문 대비 읽기 쉬운 11~12pt, 줄 간격 Multiple 1.3배, 문단 뒤 3pt. 기본 12pt를 먼저 적용하고 열 수와 자료 밀도 때문에 필요한 경우에만 11pt를 쓴다. 제출 규정이나 사용자 지시 없이 11pt 미만으로 줄여 본문이나 표를 끼워 넣지 않는다.
- 표 주석·캡션·쪽번호: 10~11pt 범위에서 읽을 수 있게 작성한다. 지정 서식의 글자 크기 규정이 이 영역에도 적용되면 그 규정을 따른다. 출처나 설명을 작게 숨기지 않는다.
배수 행간을 고정 포인트 행 높이로 잘못 적용하지 않는다. python-docx 등의 도구에서는 1.4와 1.3의 배수 줄 간격을 설정하고 XML의 auto 규칙을 확인한다. 폰트 크기, 문단 뒤 6pt와 행간은 각각 다른 속성이다.

## 문단과 정보 계층
한 문단에 여러 논점을 몰아넣지 말고 주장과 설명이 자연스럽게 이어지는 단위로 나눈다. 짧은 문장을 줄마다 끊거나 모든 문단을 동일한 길이로 강제하지 않는다. 항목 비교나 순서가 있을 때만 목록을 쓰고 들여쓰기는 일관되게 맞춘다.
굵은 글씨는 핵심 결론·조건·수치에 제한적으로 사용한다. 문단 전체를 굵게 하거나 밑줄·기울임·색상을 중복 사용하지 않는다. 제목과 본문은 검정을 기본으로 하며 표 머리글에는 명도 대비가 충분한 제한된 색상을 사용할 수 있다. 가정과 확인 필요 사항은 색상만으로 구분하지 말고 문구로 명시한다.

## 표의 가독성과 페이지 흐름
표는 비교·수치·일정·반복된 기록을 읽기 쉽게 보여줄 때 사용한다. 공식 양식이 표형인 경우는 그 구조를 유지하되, 일반 문서의 긴 설명을 표 안에 모두 밀어 넣지 않는다.
숫자·기간 열은 간결하게, 설명 열은 충분히 넓게 배분한다. 금액·단위·소수점 표기와 정렬을 통일한다. 셀의 안쪽 여백을 확보하고 얇은 회색 테두리로 행·열을 식별할 수 있게 한다. 고정 행 높이는 피한다.
여러 쪽에 걸치는 표는 머리행을 반복하고 짧은 한 기록이 불필요하게 두 페이지로 나뉘지 않도록 한다. 한 페이지보다 긴 서술형 행 전체에 분할 금지를 걸어 넘침을 만들지 않는다. 넓은 표는 열·표현·구성을 먼저 조정하고 허용되는 경우에만 가로 페이지를 고려한다.
제목은 다음 문단과 함께 배치하고, 문단의 첫 줄이나 마지막 줄만 다음 쪽으로 떨어지지 않도록 제어한다. 빈 줄을 반복하거나 공백 문자를 넣어 페이지를 맞추지 않는다. 페이지 구분 기능을 사용하되 불필요한 빈 페이지와 큰 공백을 만들지 않는다.

## 분량 조절과 최종 확인
분량을 초과하면 중복 설명과 불필요한 문장을 먼저 정리한다. 그 다음 표 너비와 페이지 흐름을 조정하며, 가독성을 희생하는 임의의 글자 축소를 마지막 해결책으로 삼지 않는다. 행간은 별도 지시가 없으면 본문 1.4배·표 1.3배를 유지한다. 사용자가 1.3~1.5배 범위에서 조정을 허용한 경우에만 그 범위 안에서 조정한다.
생성 후 실제 문서의 스타일과 직접 서식을 확인하여 기본값이 지침에만 있고 파일에는 빠지는 일이 없게 한다. 수정본에서도 기존 글자·행간·문단 간격이 섞이지 않는지 확인한다. 렌더링 가능한 환경에서는 모든 페이지를 보며 한글 누락, 표 잘림, 제목 고립, 지나친 공백과 불규칙한 정렬을 수정한다. 렌더링 미완료 상태를 시각 검증 완료라고 보고하지 않는다.
